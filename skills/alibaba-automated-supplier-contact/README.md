# alibaba-automated-supplier-contact

[![WaitHowMuch](https://api.waithowmuch.com/go/badge/alibaba-automated-supplier-contact.svg)](https://api.waithowmuch.com/go/site?from=alibaba-automated-supplier-contact)

Finds Alibaba suppliers that match your product, messages them for price tiers, MOQs, samples and lead times, and collects their replies in one table.

**Try:** "Get me quotes from Alibaba suppliers for a 1000-piece jigsaw puzzle with a custom box."

## Keys

- **Option A, your own keys:** no keys needed.
- **Option B, one WaitHowMuch key** (`WHM_API_KEY`, [get a key](https://api.waithowmuch.com/go/whm-key?from=alibaba-automated-supplier-contact)): not needed either.

How to set keys on each agent: [Data providers](../../README.md#data-providers).

## Install

Every method, including the whole plugin: [Install](../../README.md#install). This skill alone:

- Any CLI agent: `npx skills add ggballas/waithowmuch-skills --skill alibaba-automated-supplier-contact`
- claude.ai or Claude desktop: download [alibaba-automated-supplier-contact.zip](https://api.waithowmuch.com/go/zip-alibaba-automated-supplier-contact?from=alibaba-automated-supplier-contact), then Customize > Skills > Upload a skill.
