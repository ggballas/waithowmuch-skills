# amazon-case-studies

[![WaitHowMuch](https://api.waithowmuch.com/go/badge/amazon-case-studies.svg)](https://api.waithowmuch.com/go/site?from=amazon-case-studies)

Researched Amazon brands similar to a product, niche or brand, each with estimated monthly revenue, profit and margin.

**Try:** "Show me kitchen-gadget brands doing well on Amazon."

## Keys

- **Option A, your own keys:** `KEEPA_API_KEY` ([get a key](https://api.waithowmuch.com/go/keepa-api?from=amazon-case-studies), paid Keepa API plan). A niche scan instead of case studies: the top-selling brands for a keyword, revenue only, about 11 + N Keepa tokens (N listings, default 50).
- **Option B, one WaitHowMuch key** (`WHM_API_KEY`, [get a key](https://api.waithowmuch.com/go/whm-key?from=amazon-case-studies)): the researched case studies themselves, with profit and margin.

How to set keys on each agent: [Data providers](../../README.md#data-providers).

## Install

Every method, including the whole plugin: [Install](../../README.md#install). This skill alone:

- Any CLI agent: `npx skills add ggballas/waithowmuch-skills --skill amazon-case-studies`
- claude.ai or Claude desktop: download [amazon-case-studies.zip](https://api.waithowmuch.com/go/zip-amazon-case-studies?from=amazon-case-studies), then Customize > Skills > Upload a skill.
