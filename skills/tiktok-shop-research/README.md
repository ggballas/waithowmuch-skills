# tiktok-shop-research

[![WaitHowMuch](https://api.waithowmuch.com/go/badge/tiktok-shop-research.svg)](https://api.waithowmuch.com/go/site?from=tiktok-shop-research)

What a brand sells and advertises on TikTok: TikTok Shop revenue month by month, the split between its own posts, paid creators and the shop page, the videos that sell (and which run as ads), and TikTok's public ad library. Figures are Kalodata's estimates.

**Try:** "Does Mount Cleverest sell on TikTok Shop, and how much did it make there each month this year?"

## Keys

- **Option A, your own keys:** `KALODATA_API_KEY` ([get a key](https://api.waithowmuch.com/go/kalodata-api?from=tiktok-shop-research), Kalodata Open API). Pay per call in Kalodata credits (1 credit is about $0.10): shop, product, creator and video lookups 0.1 credit (about $0.01), a top-10 rank 0.1, a 12-month shop series 1.2 (about $0.12). Post dates and the ad-library link need no key.
- **Option B, one WaitHowMuch key** (`WHM_API_KEY`, [get a key](https://api.waithowmuch.com/go/whm-key?from=tiktok-shop-research)): TikTok Shop lookups without a Kalodata plan.

How to set keys on each agent: [Data providers](../../README.md#data-providers).

## Install

Every method, including the whole plugin: [Install](../../README.md#install). This skill alone:

- Any CLI agent: `npx skills add ggballas/waithowmuch-skills --skill tiktok-shop-research`
- claude.ai or Claude desktop: download [tiktok-shop-research.zip](https://api.waithowmuch.com/go/zip-tiktok-shop-research?from=tiktok-shop-research), then Customize > Skills > Upload a skill.
